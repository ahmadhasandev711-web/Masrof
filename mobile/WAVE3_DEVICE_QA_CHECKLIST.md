# موجة 3 — قائمة تحقق QA على جهاز Android

**البيئة:** APK من EAS `preview` (أو dev client)  
**الخادم:** `https://sanadat.site` (قاعدة `sanadat` على Atlas)  
**الحزمة:** `com.masrofaty.app`

سجّل لكل بند: ✅ / ❌ / ملاحظة. نفّذ مرة كـ **مالك (owner)** ومرة كـ **مشاهد (viewer)** حيث يُذكر.

---

## 11 — بعد اجتياز القائمة

1. سجّل العيوب في تذكرة / ملاحظات مع شاشة + دور + لقطة إن أمكن.  
2. أصلح blockers ثم أعد **preview APK**.  
3. عند الاستقرار: `production` → AAB للمتجر.

---

## أوامر EAS (preview APK)

```bash
cd mobile
npx eas-cli login
npm run build:android
# أو: npx eas-cli build --profile preview --platform android
```

`eas.json` → `preview` يضبط `EXPO_PUBLIC_API_URL=https://sanadat.site` و `buildType: apk`.
